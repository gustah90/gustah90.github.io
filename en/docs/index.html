Architecture, quality, and observability for this project.

Architecture and languages

Astro generates static pages in Portuguese, English, and Spanish. React can be added for interactions. Java will be integrated when it has a defined purpose.

Posting with the CMS

Sveltia CMS runs in a separate private editor. Drafts and translations go through a PR, version, changelog and CI before integration. Future-dated entries and drafts stay out of the portal. GitHub Pages deployment is a separate step after passing CI and an approved version. The portal is available for evaluation; the editor and drafts remain private.

Quality criteria

Types, lint, unit tests, coverage, Playwright with axe, and Lighthouse CI are part of the pipeline. SonarQube uses an ephemeral CI server or a configured persistent service. Manual WCAG evaluation remains required.

Pipeline targets

  • Lighthouse: performance ≥ 95; accessibility, best practices, and SEO = 100 on audited pages.
  • Playwright: keyboard navigation, languages, version, reflow, and no axe A/AA violations.
  • Per-file executable logic and component coverage: ≥ 80% for lines, statements, functions, and branches.
  • SonarQube: passing Quality Gate after configuring the service; Astro templates are also checked through lint, types, and browser tests.

Local instrumentation

By default, events and Web Vitals stay in memory on this page. Telemetry does not use cookies or persistent storage, or send automatically. Only your chosen theme preference is saved locally. Diagnostic submission is disabled on GitHub Pages, which does not host the optional collector. Query strings, error messages, stacks, and identifying data are not collected.

LCP, CLS, and INP appear when the browser provides a measurement. A missing metric does not mean zero. Records reset on each navigation.

Publishing and version

package.json defines the version, CHANGELOG.md records changes, and the Dockerfile exposes APP_VERSION and VCS_REF. The build displays the version in the footer and /version.json. Publishing requires all checks and the final review.
