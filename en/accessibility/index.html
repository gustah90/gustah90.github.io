Accessibility on this site

I want this space to be comfortable to read and easy to navigate, including with a keyboard, screen reader, or magnified content.

Reading and navigation features

You can skip straight to the content, follow a visible focus indicator when using the keyboard, and choose your language and theme. Headings organize the page, and animations respect your reduced motion preference.

How accessibility is checked

The project uses WCAG 2.2 Level AA as its accessibility target. A full manual review is still pending, including screen reader use, zoom, and content reflow on smaller screens, so full conformance has not yet been confirmed.

Automated tests help catch problems during development. Manual testing complements those checks by examining how the features work in everyday use.
