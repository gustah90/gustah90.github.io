About me

Hi, I’m Gustavo Henrique da Silva Pereira Magalhães. I’m a full-stack software engineer with more than five years of experience, and a former teacher. This is my space to share what I learn while building software.

Teaching is part of how I work

My background in teaching influences how I communicate: I value clear explanations, context and room for questions. In software teams, those habits help me discuss requirements, document decisions and collaborate with people from different disciplines.

I don’t want this blog to be just a list of technologies. I want to explain the problem, the choices I considered, the tests I ran and the limitations that remained.

My path in software

My professional experience includes Dell Technologies and Cast. At Dell, between 2021 and 2023, I worked with Angular, TypeScript, HTML, CSS and Node.js, including Express and NestJS. I integrated frontend applications with Java services and worked on an accessibility-focused browser and browser extension using Electron and Angular.

At Cast, my experience includes data-automation web applications, responsive interfaces and backend integrations using Angular, Vue.js, TypeScript, JavaScript, Node.js, Java and Python. Testing with Jest, Karma and Jasmine, code reviews, CI/CD pipelines and API documentation with OpenAPI and Swagger were also part of that work. My toolkit has included GitLab, Jenkins, Docker, Linux, Nginx and FastAPI, in Scrum and Kanban teams.

My broader full-stack background also includes React and Next.js. I see frameworks as tools to solve a particular problem; the decision should follow the product’s needs.

Education and communication

My academic path includes Systems Analysis and Development at UNIFAMETRO and Communication and Web Technologies at the University of Aveiro. Communication and technology meet in much of what interests me: understandable interfaces, accessible interactions and documentation that helps someone take the next step.

Portuguese is my native language. I’m also developing my English and Spanish. This portal starts in English and offers Portuguese and Spanish versions; translations are something I intend to review and improve, rather than present as perfect.

What I’ll share here

I want to write practical accounts of frontend and backend development, APIs, accessibility, automated tests, containers and pipelines. I’ll share decisions as well as outcomes, including things that didn’t work the first time.

One of the next topics is my experience moving an Apache/PHP setup to Nginx: how I structured the proxy and dealt with request arguments and configuration differences. That article will use actual, anonymized configurations and checks. I won’t fill in missing technical details with an invented example presented as my experience.

This portal is part of the learning

Accessibility, versioning, testing and observability are priorities here. The portal is also a work in progress, and automated checks don’t replace feedback from people using it.

You can change language using the flags, choose a light or dark theme, read the documentation and find me on GitHub.

Welcome. I hope this becomes a useful place to learn, exchange ideas and make the reasoning behind the code more visible.
