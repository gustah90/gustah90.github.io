Accesibilidad y verificación

Este proyecto busca cumplir con WCAG 2.2 en el nivel AA. Todavía no se ha demostrado la conformidad.

La base incluye HTML semántico, un enlace para saltar al contenido, foco visible, selección explícita de idioma y soporte para movimiento reducido.

Antes de declarar la conformidad, deben evaluarse todos los criterios aplicables, incluyendo el teclado, los lectores de pantalla, el zoom y la reorganización del contenido.

Las comprobaciones automáticas cubren solo parte de los requisitos y no sustituyen la evaluación manual.
